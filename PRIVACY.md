# Integritet

*English below.*

Plain Words for GitHub SWE samlar inte in några uppgifter om dig.

- Tillägget körs bara på sidor på github.com. Där läser det sidan du tittar på för att hitta knapparna som ska förklaras. Inget av det sparas eller skickas vidare.
- Det enda tillägget sparar är om förklaringarna är på eller av. Det valet sparas i din egen webbläsare.
- Tillägget skickar ingenting till någon server, har ingen spårning och ingen reklam, och använder ingen AI. Alla förklaringar finns i tillägget från början.

Hela koden är öppen i det här projektet. Frågor tas emot som en [issue](https://github.com/substnc/plain-words-for-github-swe/issues).

## English

Plain Words for GitHub SWE does not collect any data about you. It only runs on github.com, where it reads the page to find the buttons to explain. The only thing it stores is whether explanations are switched on or off, in your own browser. It sends nothing to any server, has no tracking or ads, and uses no AI.
